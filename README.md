# Smart Metro Ticketing System

A Java-based Smart Metro Ticketing System developed as a team software project.

## Project Overview

The Smart Metro Ticketing System is designed to provide users with a convenient way to manage metro journeys, including route selection, ticket purchasing, payment, and ticket management.

The system also provides administrative functions for managing stations, trains, routes, and reports.

## Features

### User Functions
- User login
- Choose metro route
- Top up balance
- Buy tickets
- Cancel tickets
- View tickets
- Make payments
- Logout

### Admin Functions
- Add stations
- Add trains
- Create routes
- View system reports
- Manage system data

### System Modules
- User Management
- Station & Route Management
- Ticket Management
- Payment Management
- File & Report Management

## Technologies

- Java
- Object-Oriented Programming (OOP)
- File I/O
- Text File Storage

## Project Structure

The system is organized into multiple modules to separate user management, transportation management, ticketing, payment, and file/report functionality.
